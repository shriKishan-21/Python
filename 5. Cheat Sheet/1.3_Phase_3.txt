⚡ Tree Recursion Template

This is worth memorizing:

def solve(root):

    if root is None:
        return ...

    left = solve(root.left)
    right = solve(root.right)

    return ...

Whenever you see a tree problem, try to identify:

What should the left subtree return?
What should the right subtree return?
How do I combine them?

That question is far more valuable than memorizing 20 tree solutions.
